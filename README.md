# TypeScript With Me 🚀

A hands-on **TypeScript learning repository** where I explore and teach TypeScript concepts from the fundamentals to more advanced features.

This repo contains practical examples and code snippets covering the most important TypeScript concepts you'll need when working with modern JavaScript and React applications.

## 📚 What You'll Learn

### 🟢 TypeScript Fundamentals

* What is TypeScript?
* What are Types?
* TypeScript Configuration
* Basic Types
* Type Inference

### 🔧 Functions & Object Types

* Functions in TypeScript
* Interfaces
* Type Aliases
* `type` vs `interface`
* Unions & Intersections
* Literal Types

### 🛡️ Type Safety

* Type Assertions
* Type Guards

### 🏗️ Advanced TypeScript

* Classes
* Generics
* Utility Types

### 🧰 Utility Types

* `Partial` vs `Required`
* `Readonly`
* `Pick` vs `Omit`
* `Record`
* `ReturnType`

### 🚀 Additional Concepts

* Enums
* Promises in TypeScript

## 🎯 Goal

The goal of this repository is to make TypeScript easier to understand through **simple explanations, practical examples, and hands-on coding**.

Whether you're learning TypeScript for the first time or coming from JavaScript, you can follow the examples step by step and practice the concepts yourself.
